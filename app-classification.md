# Lab-02 · Classification of five applications
Version 1.0 · 2026-10-30 · Team: [CertifiedVibeCoder]

| # | Application | Kind | Type(s) | Where the code runs, how it is delivered | Architecture | Top 3 qualities (why) | Filled by |
|---|-------------|------|---------|------------------------------------------|--------------|-----------------------|-----------|
| 1 | ABA Mobile (banking app) | Application | Mobile native; enterprise; cloud SaaS | Android/iOS phone, installed through Google Play or App Store. Banking servers run in the bank's data centre or cloud. | Three-tier client-server: mobile interface, banking application logic, and database. Transactions are processed and stored on the server. | **Security:** if accounts are exposed, customers lose money. **Availability:** if the service is down, customers cannot transfer money. **Performance:** if transfers take too long, customers cannot complete payments efficiently. | [Member 1] |
| 2 | Telegram | Application | Mobile native; cross-platform; web SPA; cloud SaaS | Android/iOS phones, Windows/macOS desktops and web browsers. Delivered through app stores, desktop downloads and a website URL. Servers run in Telegram's infrastructure. | Client-server architecture. Multiple clients communicate with central servers to synchronize messages and files. | **Availability:** if servers are down, users cannot communicate normally. **Security:** if private messages or accounts are exposed, users lose privacy. **Performance:** if messages are delayed, conversations become difficult. | [Member 2] |
| 3 | Car ABS (anti-lock braking system) controller | System | Embedded real-time; safety-critical | Code runs on a microcontroller/ECU inside the car. Installed by the manufacturer at the factory and updated through authorized service procedures where supported. | Embedded control loop: sensors measure wheel speed, the controller calculates slip and controls brake valves repeatedly within strict deadlines. | **Safety:** if braking control fails, the vehicle may become difficult to control. **Performance:** if the controller reacts too slowly, wheels may lock during braking. **Availability:** if the controller stops working, ABS assistance is lost. | [Member 3] |
| 4 | Moodle at ITC | Application | Web MPA; enterprise; cloud/web-hosted | Students and teachers use a browser through an ITC Moodle URL. Browser code runs on the student's device; server-side code and database run on ITC's hosting infrastructure. | Three-tier client-server: browser presentation, Moodle application logic, and database. | **Availability:** if Moodle is down during an online quiz, students cannot submit answers. **Security:** if student records are exposed, personal and academic information is compromised. **Usability:** if navigation is confusing, students may fail to find assignments or learning materials. | [Member 4] |
| 5 | Mobile Legends: Bang Bang | Application | Mobile native; cross-platform game; cloud-connected game | Android/iOS phones, installed through Google Play or App Store. Game logic and rendering run on the phone; multiplayer services run on game servers. | Client-server architecture with real-time multiplayer communication. The phone renders the game while servers coordinate matches and player data. | **Performance:** if FPS drops or input becomes delayed, gameplay becomes difficult. **Availability:** if matchmaking servers are down, players cannot join online matches. **Security:** if accounts are hacked, players can lose progress and purchased items. | [Member 1] |

**Biggest difference we found:**

The biggest difference is that the ABS controller is a safety-critical embedded system that must react within strict timing deadlines, while applications such as Telegram, Moodle and mobile banking mainly provide services through client-server communication. 

Another important difference is that ABS must operate reliably during vehicle braking, whereas the other applications can usually tolerate some delay or temporary interruption without immediately creating a physical safety risk.
